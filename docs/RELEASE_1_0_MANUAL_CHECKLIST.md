# Scribe 1.0 Manual Release Checklist

Do not mark these as passed unless they were tested on real machines.

## macOS Clean Machine

- Install from the public website.
- Confirm Gatekeeper/Open Anyway behavior.
- Complete onboarding.
- Download a Whisper model.
- Grant microphone permission.
- Record immediate speech after pressing Start.
- Pause, resume, and stop recording.
- Confirm transcription completes.
- Switch models and record again.
- Import a long M4A.
- Play transcript audio and verify word highlight/follow behavior.
- Manually scroll transcript, then use Follow Transcript.
- Create, open, archive, restore, and delete projects/recordings.
- Restart app and confirm recordings, projects, models, and settings persist.
- Resize window, use fullscreen, and confirm no global app scrollbar appears.
- Inspect DMG visual layout.
- Update from the previous public version to 1.0.0.

## Data Safety

- Existing recordings remain after update.
- Existing transcripts remain after update.
- Existing projects and archive state remain after update.
- Downloaded models remain after update.
- App language, transcription language, selected model, and onboarding state remain after update.

## Windows Clean Machine

- Install from the public download.
- Launch successfully.
- Note SmartScreen behavior if present.
- Confirm runtime binaries are available.
- Record or import audio where supported.
- Confirm transcription where supported.
- Restart app and confirm persistence.

## Hardware/Environment Notes

- Record microphone model and OS version.
- Record whether machine was clean or had an older Scribe installed.
- Keep failure logs/screenshots, but do not publish private transcripts or user data.
